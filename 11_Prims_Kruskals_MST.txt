TITLE: 11. PRIM'S AND KRUSKAL'S MINIMUM SPANNING TREE
AIM: Calculate the minimum spanning tree cost using Prim's and Kruskal's algorithms.

ALGORITHM:
1. Start.
2. Store the weighted graph as an adjacency matrix.
3. For Prim's algorithm, mark vertex 0 as visited and set the total cost to zero.
4. Find the smallest edge from any visited vertex to an unvisited vertex.
5. Add its weight to the cost and mark the new vertex visited.
6. Repeat until all vertices are visited.
7. For Kruskal's algorithm, store all edges as (weight, start vertex, end vertex).
8. Sort the edges in ascending order of weight.
9. Initially, each vertex belongs to its own set.
10. For each edge, find the sets of both endpoints.
11. If the endpoints are in different sets, select the edge, join the sets, and add its weight to the cost.
12. Stop after selecting n-1 edges.
13. Display both MST costs.
14. Stop.

PROGRAM:
graph = [
    [0, 1, 3, 0],
    [1, 0, 2, 4],
    [3, 2, 0, 5],
    [0, 4, 5, 0]
]

n = len(graph)
visited = [False] * n
visited[0] = True
prim_cost = 0

for _ in range(n - 1):
    smallest = 999
    vertex = -1
    for u in range(n):
        if visited[u]:
            for v in range(n):
                if not visited[v] and graph[u][v] != 0:
                    if graph[u][v] < smallest:
                        smallest = graph[u][v]
                        vertex = v
    prim_cost += smallest
    visited[vertex] = True

edges = [(1, 0, 1), (3, 0, 2), (2, 1, 2),
         (4, 1, 3), (5, 2, 3)]
edges.sort()
parent = list(range(n))

def find(x):
    while parent[x] != x:
        x = parent[x]
    return x

kruskal_cost = 0
count = 0

for weight, u, v in edges:
    a = find(u)
    b = find(v)
    if a != b:
        parent[a] = b
        kruskal_cost += weight
        count += 1
    if count == n - 1:
        break

print("Prim's MST Cost =", prim_cost)
print("Kruskal's MST Cost =", kruskal_cost)

OUTPUT:
Prim's MST Cost = 7
Kruskal's MST Cost = 7

RESULT: Prim's and Kruskal's algorithms calculated the minimum spanning tree cost successfully.
